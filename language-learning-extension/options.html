OpenAI API Key

Enter your OpenAI API key to enable AI-powered explanations. Your key is stored locally and never shared.

How to Get an API Key

  1. Go to platform.openai.com
  2. Create an account or sign in
  3. Navigate to API Keys in the left sidebar
  4. Click "Create new secret key"
  5. Copy the key and paste it above

Note: OpenAI charges a small fee for API usage (usually just a few cents per explanation). New accounts often receive free credits to get started.
